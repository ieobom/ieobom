## 2. 디자인이 바뀌어도 덜 흔들리게

시안은 팀원이 다시 고치고 있어요. 그래서 디자인이 바뀌어도 고칠 곳이 적게 만들어요.

- **상태는 서버가 정하고, 화면은 그리기만 해요.** 홈 카드가 '답 기다림 / 답 열림 / 먼저 보낼까요' 중 무엇인지는 DB 함수가 이름 붙인 상태값으로 돌려줘요. 시안이 바뀌면 그리는 부분만 고치면 돼요.
- **디자인 값과 공통 부품을 한 곳에 둬요.** 색·간격·글자 크기·큰 글씨 배율, 버튼·카드·기록 줄·아래 창. 39차의 "같은 정보는 같은 모양" 원칙과도 맞아요.
- **문구를 한 파일에 모아요(`src/copy/ko.ts`).** 38→39차처럼 글을 줄이는 수정은 이 파일만 고치면 돼요.
- **기능 켜고 끄기 표(`app_config`)를 둬요.** 덜 된 기능을 숨긴 채 출시하고, 시범 운영 중에 켜요. 사용량이 튀면 AI를 끌 수도 있어요.
- **화면 번호(#NN) 대신 기능 이름을 써요.** 화면 번호는 차수마다 바뀌어요.
- **시안이 고정되기 전에는** 픽셀 맞추기, 움직임, 세부 배치를 하지 않아요.

| 단위 | 디자인 영향 | 언제 |
|---|---|---|
| 1 개발 기반 · 2 데이터 · 11 운영 | 없음 | 1주차부터 |
| 5 통화 · 6 알림 | 낮음 (OS 기본 전화 화면 + 우리 화면 조금) | 1주차부터 |
| 3 로그인 · 4 가족 연결 · 7 메모·AI · 8 질문 · 9 근황 | 중간 (흐름은 그대로, 화면은 임시) | 2주차부터, 화면은 고정 뒤 다듬기 |
| 10 홈·기록·마이 | 높음 | 서버 함수는 3주차 초, 화면은 시안 고정 뒤 |

## 4. 작업 단위와 커밋

### 커밋 규칙

- **한 커밋 = 확인할 수 있는 변화 하나.** 반나절~하루 크기예요. 이틀이 넘으면 쪼개요.
- **제목은 `영역: 한 일`로 써요.** 아래 번호를 본문 첫 줄에 적어요(예: `계획 5-3`).
  - 서버: `db`(표·규칙·DB 함수), `fn`(서버 함수), `cron`(정해진 시간 작업)
  - 앱: `app`
  - 공통: `chore`, `ci`, `docs`, `release`, `ops`
- **한 커밋은 한 영역만 바꿔요.** 서버 일과 앱 일이 같이 필요하면 커밋을 둘로 나누고, 서버 커밋을 먼저 해요.
- **표를 만드는 커밋에는 보는 사람 규칙(RLS)과 그 검사(pgTAP)를 같이 넣어요.** 규칙 없이 표만 올리지 않아요.
- **서버 함수 커밋에는 시험(Deno test)을 같이 넣어요.** 바깥 서비스는 가짜로 대신해요.
- **폴더나 주요 파일을 더하면** 구조도를 갱신해요(`pnpm structure`). CI가 확인해요.
- **가지(branch)는 단위별로 짧게 따요.** 2~5커밋마다 PR → CI 통과 → main. 지금 GitHub 등급에서는 비공개 저장소에 main 보호 규칙을 걸 수 없어서, 팀 약속으로 지켜요.

**커밋 점검 기준** (계획서를 검토할 때 쓴 기준)

## 7. 시안·정책 문서에 반영해 달라고 전할 것

시안 담당 팀원에게 아래를 전해요(12-1).

1. **AI 업체**: OpenAI(GPT-4o mini) → Google(Gemini 3.5 Flash-Lite). 처리방침 국외 이전, AI 사용 안내, '최대 30일 보관' 문장(Gemini 유료 등급 기준으로 다시 확인)을 고쳐야 해요.
2. **통화 업체**: LiveKit(미국). 처리방침의 위탁·국외 이전 빈칸(18 검수 4-1)을 채워요. 나중에 국내 자체 서버로 옮기면 다시 고쳐요.
3. **사진 AI 태그 뺌**: 사진 고르기의 '고른 사진은 AI가 봐요' 문구, 처리방침의 '근황에 고른 사진' AI 전송 항목을 지워요. 사진만 보낸 근황은 주제를 직접 골라요.
4. **아이폰 'Apple로 로그인' 버튼**: 가입·로그인 화면에 추가해요.
5. **말로 답하기 60초 상한**: 녹음 중 남은 시간을 표시해요.
6. **질문 오는 요일**: 주 3번은 월·수·금이에요.
7. **통화 편한 시간 안내 피드백**: 시범 운영에서 빼요.
8. **전화는 가장 최근에 쓴 휴대폰 하나로 울려요**: 도움말 '휴대폰을 바꿨어요'에 반영해요.
9. **아이폰 기본 통화 화면 이름**: '이어봄 · 엄마'로 해요(18 검수 1-8).
10. **시범 운영 첫 주에 꺼지는 기능**: 질문·여쭤볼 이야기·근황·'지금 편한 시간' 안내가 꺼진 상태의 화면이 필요해요.
11. **상대가 탈퇴해서 끊긴 경우의 문구**: 18 검수 2-2를 반영해요.
12. **앱 오류 기록**: 국내 서버(우리 DB)에만 남겨요. 처리방침에 새 해외 업체를 더하지 않아도 돼요.

## 8. 말 풀이

| 말 | 뜻 |
|---|---|
| 보는 사람 규칙 (RLS) | 표의 줄마다 누가 읽고 쓸 수 있는지 DB가 직접 확인하는 규칙 |
| DB 함수 | 여러 단계를 '전부 되거나 전부 안 되거나'로 처리하는 함수. 앱이 이름으로 불러요 |
| 서버 함수 (Edge Functions) | 바깥 서비스 열쇠가 필요한 일을 서버에서 하는 작은 프로그램 |
| 정해진 시간 작업 (pg_cron) | 아무도 앱을 안 열어도 정한 시각에 도는 작업 |
| 통화방 · 입장 열쇠 | 두 사람이 목소리를 주고받는 방과, 그 방에 들어가는 일회용 열쇠 |
| VoIP 알림 · CallKit | 꺼진 아이폰을 전화처럼 울리는 알림과, 그때 뜨는 아이폰 기본 전화 화면 |
| 참가자·분 | 통화방에 한 사람이 1분 있으면 1. 두 사람이 15분 통화하면 30 |
| 기능 켜고 끄기 표 | 앱을 다시 내지 않고 기능을 켜고 끄는 표(`app_config`) |
| 임시 화면 | 디자인 없이 흐름만 확인하는 화면. 시안이 고정되면 바꿔요 |
| pgTAP | 보는 사람 규칙과 DB 함수가 맞게 동작하는지 자동으로 검사하는 도구 |
